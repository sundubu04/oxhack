OxHack kit

A private repo with a Claude Code setup for each phase of the hackathon, ready before the theme is announced. The app itself gets written at the event.

24 Oct 2026github.com/sundubu04/oxhackPrivate

Each phase has one thing to ask Claude for

  1. Kickoff
    oxh-kickoffReads the brief into hack/event.md: times, judging criteria and weights, rules, submission, team, hour plan
  2. Ideate
    oxh-ideate · oxh-judge15 to 25 ideas, a prior-art check, scores against the event's criteria, a blind panel score, an idea board page
  3. Spec
    oxh-spec · oxh-plannerA plan written back from the demo: beats, outcomes, the spike, owned slices, contracts, a cut list
  4. Build
    oxh-frontend-engineer · oxh-ui-kitThe demo path end to end, on one light UI kit with its own checker
  5. Polish
    oxh-ui-polish · oxh-ui-criticCompared with apps that do the same job; a blind critic picks three fixes a round
  6. Freeze
    touch .freezeA hook refuses edits to app code until someone lifts it. An edit during a rehearsal broke flow-er's demo
  7. Demo
    oxh-demoScripted takes of the real app, cut with zooms, ▶▶ badges, cards and captions
  8. Pitch
    oxh-pitch · oxh-slidesUp to eight slides on the Slides type, speaker notes, two timed rehearsals, a Q&A sheet
  9. Wrap-up
    oxh-wrapupSubmission checklist, README for judges, licence and public checks, the post

Team pages (idea board, plan, architecture, status, results, run sheet) come from oxh-artifact: a house template, sources in docs/pages/, every link listed in hack/artifacts.md so it survives a republish. This page is the first one.

Before the event

  • Open Claude Code in the folder once and trust it, so the hooks and the countdown start.
  • Add the team as collaborators on the repo. Nobody else has access yet.
  • When the brief is out: "run oxh-kickoff" with the link or the slides.
  • On the laptop that records the demo: cd demo && npm i.
  • If OxHack wants a public repo, decide whether the darling-agentic pieces may go public. oxh-wrapup lists them.
