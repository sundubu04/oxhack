A context diagram, nine boxes at most

Every arrow one way and labelled with intent; a key when styles mean something (C4 checklist)

What runs where

A layered stack, closest to the user on top

Layers of equal height; the layer the talk is about outlined (Duarte stack)

One request in order

A sequence diagram, five parts at most

Number the messages; past about eight, split the slide (Mermaid, C4 dynamic)

Who does what

A swimlane, four lanes at most

Straight lines and right angles only (AWS diagram guidelines)

A config or an API

A code panel, twelve lines at most

Notes keyed to line numbers, never arrows across the code

A value against a target

A bullet graph, not a gauge

A bar, a target tick and up to three ranges in one grey (Few, bullet graph spec)
